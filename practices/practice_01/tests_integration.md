# Integration-проверки

| Связь компонентов | Что может сломаться | Как воспроизводим | Ожидаемый результат | Evidence |
|---|---|---|---|---|
| FastAPI эндпоинт ↔ ReviewService | Неправильная распаковка тела запроса или потеря полей | Отправка POST `/api/reviews` с телом `{"diff": "valid diff"}` через TestClient | HTTP 200, тело ответа содержит `summary`, `risks`, `checks` | Интеграционный тест `test_api_reviews_happy_path` |
| ReviewService ↔ Внешний LLM (Таймаут REL-1) | Зависание сервиса при лаге LLM >10 с | Мок LLM-клиента с искусственной задержкой `sleep(15)` | Прерывание по таймауту ровно через 10 с, контролируемый HTTP 503 без трейса | Тест `test_api_reviews_llm_timeout_handled` с замером времени |
| ReviewService ↔ Внешний LLM (Сбой провайдера) | 500 Internal Server Error при исключении со стороны LLM (502/ConnectionError) | Мок LLM выбрасывает `HTTPException(502)` | Сервис перехватывает сбой и возвращает контролируемый 503 Service Unavailable | Тест `test_api_reviews_llm_failure_controlled_503` |
| ReviewService ↔ LLM (Утечка секретов SEC-1) | В промпт LLM уходит незамаскированный diff | Отправка diff с секретом, мок LLM логирует полученный `prompt` | В аргументе `prompt` мока LLM секрет отсутствует, подставлен `[REDACTED]` | Тест `test_llm_prompt_contains_no_raw_secrets` |

## Как использовали AI

- Для чего: Формирование интеграционных сценариев взаимодействия компонентов и обработки сбоев LLM
- Тип промпта: RCTF (интеграционное тестирование с моками)
- Строка в [`prompts.md`](prompts.md): P1-02
- Что проверили и исправили сами: Добавили обязательную проверку поведения при сбое внешнего LLM-провайдера и верификацию аргументов мока на отсутствие незамаскированных секретов.
