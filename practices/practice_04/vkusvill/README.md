# ВкусВилл Радар (VV Radar)

Интерактивный гео-дашборд и карта магазинов сети **ВкусВилл**, работающий на базе официального MCP-сервера (`https://mcp.vkusvill.ru/mcp`).

## Стек технологий

* **Backend**: Pure Go (Go 1.25+, стандартная библиотека: `net/http` с современным роутингом, `html/template` через `embed.FS`, `sync`, `encoding/json`). Без сторонних фреймворков.
* **Frontend**:
  * **HTMX 2.x**: Бесшовное динамическое обновление списка магазинов и фильтров без перезагрузки страниц.
  * **Alpine.js 3.x**: Управление адаптивным состоянием и мобильными вкладками.
  * **Leaflet.js + Leaflet.markercluster**: Интерактивная карта с кастомными маркерами ВкусВилла и плавной кластеризацией.
  * **Tailwind CSS**: Чистый UI в фирменной палитре ВкусВилл (`#008248`), созданный по гайдлайнам `ui-ux-pro-max` и `web-design-guidelines`.

## Возможности

1. **Интерактивная карта сети**:
   - Отображение магазинов с кастомными пинами и всплывающими карточками (адрес, время работы, рейтинг, сервисы).
   - Кластеризация маркеров при удалении масштаба.
   - Двусторонняя синхронизация: клик по карточке центрирует карту, клик по маркеру подсвечивает карточку в списке.

2. **Быстрые фильтры удобств (в 1 клик)**:
   - ☕ Кафе / Кофе с собой
   - 🍊 Сокомат (свежевыжатый апельсиновый сок)
   - 🥖 Пекарня со свежей выпечкой
   - 🍷 Винный отдел
   - 🔋 Прием батареек / ♻️ Сбор крышечек
   - 🐟 Рыбная витрина / 🥩 Мясная витрина
   - 👕 Сбор вещей / 🧊 ВкусВилл Айс

3. **Геолокация («Рядом со мной»)**:
   - Определение координат пользователя через HTML5 Geolocation API.
   - Расчет точного расстояния (метры/километры) по формуле гаверсинусов и сортировка магазинов от ближайшего.

4. **Умный кэш (Rate-Limit Safe)**:
   - Потокобезопасный in-memory кэш защищает от превышения лимитов MCP-сервера ВкусВилл (60 req/min).

5. **Карта всей сети (инкрементально)**:
   - Фоновый прогрев (`internal/mcp/warmer.go`) тянет каталог постранично: сначала по одному срезу на каждый регион (быстрое георазнообразие), затем полный обход, с паузой между запросами и без превышения лимита.
   - Карта накапливает маркеры по мере прогрева, а не показывает одну страницу; эндпоинт `/api/shops/points?scope=all` отдаёт всё накопленное и прогресс.

## Быстрый запуск

### 1. Запуск через Go:
```bash
make run
# или напрямую:
go run cmd/server/main.go
```

Приложение будет доступно по адресу: **http://localhost:8080**

### 2. Сборка бинарника:
```bash
make build
./bin/vkusvill
```

### 3. Запуск тестов:
```bash
make test
```

## Переменные окружения

* `PORT` — Порт сервера (по умолчанию `8080`).
* `MCP_URL` — URL MCP-сервера ВкусВилла (по умолчанию `https://mcp.vkusvill.ru/mcp`).
* `WARM_MAX_PAGES` — ограничить фоновый прогрев каталога числом страниц (по умолчанию `0` — все страницы).

## Разработка

Требования: Go 1.27+, `gofmt`, `git`.

```bash
make init-hooks   # один раз: включить git-хуки из .githooks/
make test         # go test ./...
make build        # сборка бинарника в bin/
```

Git-хуки (`.githooks/`): `pre-commit` прогоняет `gofmt`/`go vet`/`go test`, `commit-msg` требует Conventional Commits.

Автопроверка после правок кода выполняется плагином OpenCode `.opencode/plugins/vv-checks/`.
