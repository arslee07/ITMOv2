# Макет и прототип

## Ссылка

Прототип в v0: **https://v0.app/chat/gIQDdcFAfGT**

Чат открыт по ссылке (unlisted), аккаунт не нужен. Внутри — живой предпросмотр, код и история сообщений.
Скриншоты пяти состояний лежат в `screens/`, экспорт файлов — в `v0/`.

## Что сделал AI

v0 по промпту собрал Next.js-прототип с Tailwind и shadcn/ui:

- две колонки: форма слева, очередь справа;
- панель «Состояния» с переключателями «Исходное», «Ввод», «Загрузка», «Результат», «Ошибка»;
- форма с обязательными полями, ошибками и блокировкой на время отправки;
- карточки тикетов с типом, статусом и уверенностью;
- диалог деталей с Escape и кнопкой «Взять в работу»;
- визуальное направление: тёплый фон, графитовый текст, индиго-акцент, моноширинные метки,
  тонкие рамки, без градиентов и стекла.

## Промпт

```text
Собери интерактивный высокодетализированный прототип консоли триажа обращений
для службы поддержки. Стек: Next.js, React, TypeScript, Tailwind, shadcn/ui.
Весь интерфейс и тексты — на русском.

Задача пользователя: заполнить баг-репорт, отправить, увидеть, как AI определяет
тип (bug / task / feature) и уверенность, и найти созданный тикет в очереди.

Экран: верхняя панель с названием и бейджем «AI-классификация»; сетка из формы
и очереди; поля «Заголовок», «Описание», «Автор»; кнопка «Отправить обращение»;
ошибки под полями; загрузка «Классифицируем…»; успех с сообщением и новой карточкой;
пустое состояние «Пока нет обращений»; карточки с типом, статусом, уверенностью,
автором и кнопкой «Подробнее»; диалог с деталями и действием «Взять в работу».

Для ревьюера — панель «Состояния» из пяти переключателей: «Исходное», «Ввод»,
«Загрузка», «Результат», «Ошибка». Обычное взаимодействие тоже работает:
форма отправляется, показывается загрузка, результат, ошибка.

Визуальное направление: диспетчерская, а не SaaS-лендинг. Тёплый светлый фон
#F7F6F3, графитовый текст #1C1B19, индиго #4F46E5 только для главного действия
и фокуса, тонкие рамки 1px, радиус 12px, без градиентов, стекла, огромных героев
и эмодзи. Inter для интерфейса, IBM Plex Mono для мелких меток. Плотная, но
воздушная сетка. Готовые компоненты shadcn/ui. Видимый focus ring, подписи полей,
сценарий с клавиатуры.

Тексты короткие, без маркетинга и канцелярита.
```

Вторым сообщением попросил сделать «Исходное» пустым, а примеры тикетов показывать
в состояниях «Ввод», «Загрузка» и «Ошибка». Так на первом экране видно пустое состояние.

## Что изменил после проверки

- Нажал на все пять состояний и проверил, что переключатели не ломают форму.
- Убедился, что «Исходное» показывает пустую очередь, а не примеры.
- Открыл чат по ссылке и выставил доступ `unlisted`, чтобы ревьювер мог посмотреть без аккаунта.
- Перенёс направление в рабочий интерфейс: токены цвета и шрифта, моноширинные метки,
  карточки с `TRI-…`, бейдж `AI · 94%`, русские статусы, диалог с сеткой метаданных.
- Убрал из своего интерфейса лишние подсказки и градиентный фон, которых нет в макете.
