# Proposal

## Why

Список магазинов сейчас упорядочен неявно: по расстоянию, если включена
геолокация, иначе — в порядке ответа MCP. Пользователь не может разложить выборку
по рейтингу или адресу, а после обновления данных порядок меняется сам.

## What Changes

- Добавить выбор порядка списка: по расстоянию, по рейтингу, по адресу.
- Хранить выбор пользователя локально, чтобы он переживал перезагрузку.
- Пункт «по расстоянию» недоступен, пока координаты неизвестны.
- Серверный API и формат точек не меняются.

Не входит: сортировка маркеров карты, новые фильтры, изменение серверных
эндпоинтов.

## Capabilities

### New Capabilities

- `shop-list-sorting`: выбор и сохранение порядка списка магазинов.

### Modified Capabilities

Нет.

## Impact

`internal/web/static/js/app.js`, `internal/web/templates/partials/filters.html`.
Серверные файлы не затрагиваются.
