# Feature Specification: Экспорт видимых магазинов в CSV

**Feature Branch**: `001-export-shops-csv`

**Created**: 2026-10-25

**Status**: Draft

**Input**: User description: "Экспорт видимых данных в файл — выгрузить текущую выборку магазинов в CSV"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Выгрузить текущую выборку (Priority: P1)

Пользователь отфильтровал магазины (город, удобство, поиск) и нажимает
«Экспорт CSV», чтобы забрать список в таблицу и отправить коллеге.

**Why this priority**: это единственная ценность фичи: без файла остальное не имеет
смысла.

**Independent Test**: открыть `/`, выбрать город, нажать «Экспорт CSV» — скачивается
файл с магазинами выбранного города.

**Acceptance Scenarios**:

1. **Given** в кэше есть магазины и выбран город, **When** пользователь нажимает
   «Экспорт CSV», **Then** скачивается файл, в котором только магазины этого города.
2. **Given** выбран поиск по адресу, **When** пользователь нажимает «Экспорт CSV»,
   **Then** в файле только магазины, подходящие под поиск.
3. **Given** фильтры не заданы, **When** пользователь нажимает «Экспорт CSV»,
   **Then** в файле все магазины, накопленные к этому моменту.

### User Story 2 - Понятные состояния кнопки (Priority: P2)

Пользователь видит, что экспорт выполняется, и получает сообщение, если файл
собрать не удалось.

**Why this priority**: без обратной связи кнопка «молчит» и пользователь жмёт её
повторно.

**Independent Test**: заблокировать сеть в DevTools и нажать «Экспорт CSV» —
появляется сообщение об ошибке, кнопка снова активна.

**Acceptance Scenarios**:

1. **Given** список пуст, **When** страница отрисована, **Then** кнопка «Экспорт
   CSV» недоступна.
2. **Given** экспорт выполняется, **When** запрос в полёте, **Then** кнопка
   заблокирована и показывает состояние загрузки.
3. **Given** сервер вернул ошибку, **When** ответ пришёл, **Then** в области списка
   показано сообщение об ошибке, кнопка снова активна.

### User Story 3 - Экспорт с расстоянием (Priority: P3)

Пользователь нажал «Рядом со мной» и хочет видеть расстояние в файле.

**Why this priority**: дополняет выборку, но фича полезна и без него.

**Independent Test**: нажать «Рядом со мной», затем «Экспорт CSV» — в файле есть
колонка с расстоянием.

**Acceptance Scenarios**:

1. **Given** координаты известны, **When** пользователь экспортирует выборку,
   **Then** в файле заполнена колонка расстояния и строки отсортированы по
   возрастанию расстояния.

### Edge Cases

- Список пуст: кнопка недоступна, запрос не отправляется.
- В адресе есть `;`, кавычки и перевод строки: файл остаётся корректным CSV.
- Магазин без рейтинга или без метро: поля пустые, строка не ломается.
- Экспорт во время фонового прогрева: в файл попадает то, что уже накоплено.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Кнопка «Экспорт CSV» MUST находиться в шапке списка магазинов рядом
  со счётчиком.
- **FR-002**: Кнопка MUST быть недоступна, пока в списке нет ни одного магазина.
- **FR-003**: Нажатие MUST инициировать скачивание файла без перезагрузки страницы.
- **FR-004**: Во время запроса кнопка MUST быть заблокирована, получать `aria-busy`
  и показывать состояние загрузки в `#export-status` до ответа сервера.
- **FR-005**: При ошибке MUST отображаться текст ошибки в области списка, кнопка
  MUST вернуться в исходное состояние.
- **FR-006**: Имя файла MUST содержать дату и время выгрузки.
- **FR-007**: Кнопка MUST иметь `aria-label`, видимый фокус и размер не меньше
  44×44 px.
- **FR-008**: Экспорт MUST учитывать активные фильтры: город, удобство, поиск,
  координаты.

### Key Entities

- **Выборка**: магазины, которые пользователь видит при текущих фильтрах.
- **Файл экспорта**: CSV-таблица с фиксированным набором колонок (см.
  `logic-spec.md` и `contract.md`).

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Пользователь получает файл по нажатию кнопки за один шаг, без
  промежуточных диалогов.
- **SC-002**: Содержимое файла совпадает с текущей выборкой по фильтрам; файл не
  ограничен 500 карточками, которые рисует интерфейс.
- **SC-003**: Ошибка экспорта видна пользователю и не оставляет кнопку в
  заблокированном состоянии.

## Assumptions

- Список магазинов уже загружается клиентом и хранится в `allShops`.
- Формат файла — CSV, детали в `logic-spec.md`.
