# Общий контракт двух команд

**Фича**: экспорт видимых магазинов в CSV
**Версия**: 2 (после согласования, до кода)
**Дата**: 2026-10-25
**Участники**: команда UI (`ui-spec.md`), команда логики (`logic-spec.md`)

Контракт фиксирует стык, который обе команды обязаны соблюдать. Всё, что не
описано здесь, команды решают внутри своей спеки.

## 1. Точка вызова

| Элемент | Значение |
|---|---|
| Метод и путь | `GET /api/export.csv` |
| Кто вызывает | кнопка «Экспорт CSV» в шапке списка |
| Тело запроса | отсутствует |
| Аутентификация | нет (локальный сервис) |

## 2. Параметры запроса

Те же, что у `/api/shops/points`, с той же семантикой и той же валидацией:

| Параметр | Тип | Смысл |
|---|---|---|
| `city_id` | целое ≥ 0 | фильтр по городу |
| `feature_id` | целое ≥ 0 | фильтр по удобству |
| `region_id` | целое ≥ 0 | фильтр по региону |
| `subway_id` | целое ≥ 0 | фильтр по метро |
| `q` | строка ≤ 100 рун | поиск по адресу и метро |
| `lat`, `lon` | пара чисел | координаты пользователя |

Решения:

- **Клиент передаёт только активные фильтры.** Пустые значения не отправляются.
- **`scope=all` не используется**: экспорт всегда строится по накопленному кэшу.
- **Расстояние считается на сервере**: клиент не пересчитывает его повторно.

## 3. Успешный ответ

| Заголовок | Значение |
|---|---|
| `Content-Type` | `text/csv; charset=utf-8` |
| `Content-Disposition` | `attachment; filename="vkusvill-shops-YYYY-MM-DD-HHMM.csv"` |
| `Cache-Control` | `no-store` |

Тело: UTF-8 BOM, разделитель `;`, конец строки CRLF, экранирование RFC 4180.

Колонки (порядок обязателен):

```
ID;Адрес;Город;Рейтинг;Широта;Долгота;Метро;Удобства;Расстояние
```

- `ID` — целое.
- `Рейтинг` — число с точкой (`4.7`) или пусто.
- `Широта`, `Долгота` — числа с точкой.
- `Рейтинг` округляется до одного знака (`4.75` → `4.8`).
- `Метро`, `Удобства` — через запятую с пробелом внутри поля; пусто, если данных нет.
- `Расстояние` — как в интерфейсе (`850 м`, `1.4 км`); пусто, если координат нет.

Сортировка: при переданных `lat`/`lon` — по возрастанию расстояния, магазины без
координат идут в конце по `ID`; без координат — по `ID`. Пустой кэш — валидный
ответ: файл из одной строки заголовка.

Объём: экспорт отдаёт **все** магазины, подходящие под фильтр, и не ограничен
клиентским лимитом `MAX_CARDS = 500`, который действует только на отрисовку
карточек. Если подходящих больше 20 000 — `413`.

## 4. Ошибки

| Код | Условие | Тело | Что делает клиент |
|---|---|---|---|
| `400` | некорректный параметр | `text/plain`, имя параметра | показывает текст в области списка |
| `413` | подходящих магазинов > 20 000 | `text/plain` | показывает текст |
| `500` | внутренняя ошибка | `text/plain` | показывает общее сообщение |

Клиент не парсит тело ошибки как JSON и не пытается сохранить файл при не-2xx.

## 5. Поведение UI

- Кнопка активна только при непустом списке.
- На время запроса кнопка блокируется; состояние загрузки снимается в `finally`.
- Имя файла берётся из `Content-Disposition`; если заголовка нет — клиент
  подставляет `vkusvill-shops-<дата>.csv`.
- Ошибка выводится в `#export-status` внутри области списка, кнопка остаётся
  доступной.

## 6. История согласования

| # | Расхождение в черновиках | Решение | Чья уступка |
|---|---|---|---|
| 1 | UI-черновик собирал CSV в браузере из `allShops`; логика делала endpoint | сервер отдаёт файл, клиент только инициирует скачивание | UI |
| 2 | UI-черновик: кнопка всегда активна и запрос уходит при пустом списке | кнопка недоступна при пустом списке; сервер при этом корректно отдаёт файл с заголовком | обе |
| 3 | Логика-черновик: разделитель `,`; UI ожидал открытие в Excel без настроек | разделитель `;` + BOM | логика |
| 4 | Логика-черновик: `null` для пустых значений | пустые поля, без `null` и прочерков | логика |
| 5 | UI-черновик: расстояние считает клиент | расстояние считает сервер, клиент показывает готовую строку | UI |
| 6 | «Видимые» понималось как 500 отрисованных карточек | «видимые» = все магазины под фильтром; лимит карточек к экспорту не применяется | обе |
| 7 | Магазины без координат при сортировке по расстоянию мерились от (0,0) | такие магазины уходят в конец файла, расстояние пустое | логика |
| 8 | UI не показывал, что идёт запрос | кнопка получает `aria-busy` и пульсацию, статус пишется в `#export-status` | UI |

Версии «до» лежат в `history/`, актуальные спеки — `ui-spec.md` и `logic-spec.md`.
