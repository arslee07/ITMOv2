# [ДО СОГЛАСОВАНИЯ] Спека логики: экспорт магазинов

Статус: черновик команды логики, версия 1. Не согласован с командой UI.

## Замысел

Новый endpoint `GET /api/export.csv`, который сериализует накопленный кэш в CSV.

## Требования (черновик)

- Endpoint без параметров: отдаёт всё, что есть в кэше.
- Разделитель `,`, экранирование по RFC 4180, без BOM.
- Пустые значения — `null`, чтобы отличать «нет данных» от пустой строки.
- Сортировка всегда по `ID`.
- `Content-Type: text/csv`, имя файла фиксированное.
- Лимита строк нет.

## Открытые вопросы к команде UI

- Как клиент узнает, что файл готов?
- Нужны ли фильтры в экспорте, если клиент может отфильтровать сам?
