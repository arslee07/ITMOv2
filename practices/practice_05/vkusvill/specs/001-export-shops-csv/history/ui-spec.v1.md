# [ДО СОГЛАСОВАНИЯ] UI-спека: экспорт магазинов

Статус: черновик команды UI, версия 1. Не согласован с командой логики.

## Замысел

Кнопка «Экспорт CSV» в шапке списка. CSV собирается **в браузере** из уже
загруженного `allShops`: берём текущую выборку, формируем строки и скачиваем через
`Blob` + `URL.createObjectURL`.

## Требования (черновик)

- Кнопка всегда активна.
- Клиент сам считает расстояние по координатам и форматирует его.
- Разделитель `,`, кодировка UTF-8 без BOM.
- Пустые значения пишутся как `null`.
- Имя файла: `shops.csv`.

## Открытые вопросы к команде логики
