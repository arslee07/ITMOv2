# Переговорный чат двух команд

Эмуляция: два независимых чата готовят спеки («UI» и «логика»), третий чат
сводит их и ищет расхождения. Решение по каждому пункту принимает человек.

## Черновики («до»)

`specs/001-export-shops-csv/history/ui-spec.v1.md` и `logic-spec.v1.md`.

Расхождения, найденные при сведении:

1. UI собирал CSV в браузере и считал расстояние сам; логика делала endpoint.
2. UI: кнопка активна всегда; логика: пустой кэш — валидный файл с заголовком.
3. Логика: разделитель `,`, без BOM; UI ожидает открытие в Excel без настроек.
4. Логика: `null` для пустых значений; UI ждёт пустые ячейки.
5. UI: имя файла `shops.csv`; логика: сервер отдаёт имя в `Content-Disposition`.

Решения и уступки — в `specs/001-export-shops-csv/contract.md`, раздел
«История согласования». Итоговые спеки: `ui-spec.md`, `logic-spec.md`.

## Перекрёстное ревью после реализации

Отдельный чат проверил код против обеих спек. Найдено и исправлено:

| Пункт | Решение |
|---|---|
| `region_id`/`subway_id` принимались, но не фильтровали | добавлены фильтры по региону и метро + тесты |
| «Видимые» понималось как 500 карточек, а сервер отдаёт весь кэш | зафиксировано в контракте: экспорт = все подходящие, лимит карточек не применяется |
| Магазины без координат при сортировке по расстоянию мерились от (0,0) | уходят в конец файла, расстояние пустое + тест |
| Кнопка не показывала загрузку | `aria-busy` + пульсация + текст в `#export-status` |
| Fallback-имя файла не по контракту | локальное время, формат `YYYY-MM-DD-HHMM` |
| Не было тестов на границу лимита, `lon` без `lat`, сырые CRLF/кавычки | тесты добавлены |
| `revokeObjectURL` сразу после `click()` | отзыв через 1 с |

## Что осталось за кадром

UI-сценарии (пусто → busy → ошибка → скачивание) не автоматизированы: в проекте
нет браузерных тестов. Проверены чтением кода и отданным HTML, ручная демонстрация
в браузере — на защите.
