# Ревью 1 — независимый чат

Проверяющий: отдельный агент без контекста автора (не менял файлы).

## Замечания

1. **Blocker — нулевые координаты.** `buildPageData` определяет наличие геолокации
   по `params.UserLat != 0 && params.UserLon != 0`, а спека обещает сортировку для
   любой пары, включая `0`. Пара `lat=0&lon=37` прошла бы валидацию и молча не
   отсортировалась.
2. **Blocker — `page` выпал из требований.** В proposal и design он есть, в spec —
   нет: поведение `page=abc`, `page=1.5`, `page=-5` не определено.
3. **Blocker — ветка `scope=all` вне контракта.** `HandleShopsPoints` при
   `scope=all` не разбирает параметры вовсе, значит `?scope=all&lon=200` вернёт
   `200` вопреки требованию.
4. **Пустые `lat`/`lon`.** D4 объявляет пустую строку «не задан» только для id;
   случаи `lat=&lon=37` и `lat=&lon=` не описаны.
5. **Nit — `NaN`/`Inf`.** `strconv.ParseFloat` их принимает, а сравнения диапазона
   с NaN ложны.
6. **Nit — неверное утверждение про HTMX.** В шаблонах нет `hx-get`/`hx-target`,
   поэтому «HTMX покажет текст ошибки в списке» — неправда; `/` на 400 отдаст
   голый текст.
7. **Nit — тесты и задачи.** `nil`-кэш не проверит «MCP не вызван», а для
   `scope=all` упадёт; пример `curl` в README, на который ссылается задача 3.1,
   отсутствует.

## Решения человека (принято)

| # | Решение |
|---|---|
| 1 | Ввести явный признак `HasLocation` (оба параметра присутствуют), а не сравнение с нулём. `0,0` — валидная точка, сортировка работает. |
| 2 | `page`: отсутствует/пусто → 1; целое < 1 → 1 (как раньше); нецелое или нечисловое → 400. |
| 3 | `scope=all` явно исключён из контракта: параметры фильтра игнорируются, валидация не применяется. |
| 4 | Пустая строка = «параметр не задан» для всех параметров; `lat=&lon=37` = только `lon` → 400. |
| 5 | Требовать конечное число (`NaN`, `Inf` → 400). |
| 6 | Исправить design: ошибки текстовые, HTMX-обмена в текущих шаблонах нет. |
| 7 | Тест «MCP не вызван» — через `httptest`-счётчик обращений; в README добавить реальный пример `curl`. |

Все семь замечаний приняты, спека, design и tasks обновлены до apply.
