# Проверка 1 — независимый чат

Проверяющий: отдельный агент (не автор кода). Проверял требования
`specs/shop-filtering/spec.md` на запущенном сервисе и через `go test`.

## Что проверено

`make build`, `go vet ./...`, `go test -count=1 ./...` — зелёные. Сервис запущен
(`PORT=8099 WARM_MAX_PAGES=1`), проверки через `curl`:

| Условие | Ожидание | Факт |
|---|---|---|
| `lat=55.75&lon=37.62` | 200 | 200, `application/json`, `distance_str` есть |
| `city_id=abc` | 400 + имя параметра | 400, `text/plain`, «некорректный параметр city_id…» |
| `feature_id=coffee` | 400 | 400, имя параметра в теле |
| `city_id=-5` | 400 | 400, «значение не может быть отрицательным» |
| `region_id=1.5` | 400 | 400, «ожидается целое число» |
| `page=0`, `page=-5` | как без `page` | 200, тело совпало (md5) |
| `page=abc`, `page=1.5` | 400 | 400, имя параметра `page` |
| `lat=&lon=37.62` | 400 | 400, «укажите обе координаты» |
| `lat=95`, `lat=NaN`, `lon=200` | 400 | 400, имя параметра и причина |
| `lat=0&lon=0` | 200 + расстояние | 200, `distance_str` у всех точек |
| `q=  Пятёрочка ` | обрезка | 200, поиск по обрезанной строке |
| `q` 100 / 101 руна | 200 / 400 | 200 / 400 |
| `q=a%09b` | 400 | 400, «управляющие символы недопустимы» |
| `scope=all&lon=200` | 200, без валидации | 200, `{points, stats}` |
| Отказ не идёт в MCP | 0 обращений | счётчик стаба: 0 после 6 отказов, 2 на валидный запрос |

## Найдено и исправлено

1. JSON-эндпоинт не сортирует точки по расстоянию → в spec сценарий сужен до
   заполненного `distance_str`; порядок точек не нормируется (списку и карте
   порядок не нужен).
2. `app.js` считал `0,0` отсутствием координат → добавлен `hasCoords`, проверки
   переведены на него; `filterKey` учитывает признак, чтобы список перерисовывался.
3. Не было теста `subway_id=0` → добавлен.
4. Тесты обработчиков назывались по маршруту, но часть шла в `default` →
   диспетчеризация через поле `handle`.
5. `q=%09` после `TrimSpace` проходил → управляющие символы проверяются до обрезки.
6. README говорил «символов» → «рун», добавлен пример `curl`.

## Остаточное ограничение (вне границ изменения)

URL-пара `?lat=&lon=` не доходит до клиента: hidden-поля заполняет только кнопка
геолокации. Серверный `HasLocation` и клиентский `hasCoords` согласованы, но
сортировка в браузере включается после клика «Рядом со мной», а не из ссылки.
Зафиксировано в design D7; менять навигацию в этой фиче не стали.
