# ReAct

- Цель: Найти до 3 доказанных рисков в TRAINING_PR.diff в пошаговом цикле и немедленно остановиться.
- Доступные входы: TRAINING_PR.diff, правила CASE.md (SEC-1..QA-1).
- Разрешённые действия: inspect(file, lines), check_rule(rule_id), emit_risk(file, line, evidence,
  rule), stop().
- Запрещённые действия: Изменять код, выполнять shell-команды, делать approve/merge (SCOPE-1),
  сканировать дальше после нахождения 3 рисков.
- Максимальное число шагов: 5.
- Условие остановки и вопроса человеку: Накопление ровно 3 подтвержденных рисков либо обнаружение
  неоднозначности, требующей решения человека.

## Запрос

Ты работаешь строго по циклу ReAct (Thought -> Action -> Observation).
Проанализируй TRAINING_PR.diff. На каждом шаге выбирай одно разрешённое действие: inspect,
  check_rule, emit_risk или stop.
  Как только набрано 3 риска, немедленно выполни stop. Максимум 5 шагов.
