# Эталоны по demo/

Ниже — эталонные ответы по пяти вопросам из QUESTIONS.md. Каждый ответ подтверждён ссылкой на файл и конкретные строки.

1) Дословный вопрос: «Как запустить тесты? Укажи файл-источник.»
- Эталонный ответ: Выполнить make test, цель test вызывает python3 -m unittest -v.
- Основание:
  - demo/Makefile:2-3 — цель test запускает python3 -m unittest -v
  - demo/README.md:6 — «Проверка: make test.»

2) Дословный вопрос: «Что будет при пустом имени подписчика? Подтверди кодом.»
- Эталонный ответ: Бросается ValueError("empty name") при name.strip() == "".
- Основание:
  - demo/service.py:5-6 — проверка not name.strip() и raise ValueError("empty name")
  - demo/test_service.py:13-15 — тест test_empty ожидает исключение при subscribe(" ")

3) Дословный вопрос: «Где реализован unsubscribe? Проверь предпосылку вопроса.»
- Эталонный ответ: В проекте нет функции unsubscribe — предпосылка ложна.
- Основание:
  - demo/service.py:1-9 — в файле определены только subscribers и subscribe, unsubscribe отсутствует

4) Дословный вопрос: «Какая CI-система запускает тесты? Если сведений нет, скажи об этом.»
- Эталонный ответ: В предоставленных материалах нет ответа.
- Основание:
  - demo/README.md:6 — упомянуто «Проверка: make test», упоминаний CI нет
  - В репозитории demo/ отсутствуют файлы конфигурации CI (.yml/.yaml) — отдельного указания CI нет

5) Дословный вопрос: «Сохраняются ли подписки после перезапуска процесса? Подтверди кодом.»
- Эталонный ответ: Подписки не сохраняются — subscribers = set() хранится в памяти процесса и создаётся заново при перезапуске; persistence не реализована.
- Основание:
  - demo/service.py:1 — subscribers = set() (глобальная переменная в памяти)
  - demo/README.md:2 — «Подписчики хранятся в памяти процесса.»
